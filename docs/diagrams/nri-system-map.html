Dashboard

Before building

Decisions to confirm

Remittances get their own ledger instead of being a spending category.

A transfer has two amounts, a rate and a fee, and a purpose that feeds three other modules. Recommended. Your existing "Family / India" rows would be moved over on first load.

Account balances are entered as a snapshot each cycle.

The workbook has flows but no opening balances, so balances can't be derived. Recommended: you type each account's balance on review day; the app shows the change since last cycle.

A remittance marked "loan EMI" or "prepayment" updates the loan schedule automatically.

Saves entering the same payment twice. The schedule would show which months were actually paid versus planned.

Category budgets are set once and carried forward each cycle.

You edit them only when something changes, rather than re-entering every 25th.

Keep the app as one HTML file.

It opens by double-click and your data stays in finance-data.json beside it. Nine screens fit as tabs; splitting into separate pages would break the shared Store.
