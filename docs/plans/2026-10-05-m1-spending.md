# M1 Spending Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** Daily expense logging in v2 on the laptop: a ledger with filters, quick-add, category management and a basic cycle dashboard, with the database refusing cross-user links.

**Architecture:** Migration 0003 replaces every single-column foreign key with a composite `(user_id, …)` key. `packages/core` gains cycle-range and cycle-summary functions; `packages/contracts` gains schemas for categories, transactions, accounts and the dashboard. The Hono API adds `/api/categories`, `/api/transactions`, `/api/accounts`, `/api/dashboard`, maps foreign-key/unique violations and JWKS outages to proper errors. The Vue app gets a responsive shell (drawer / bottom nav), a sign-in dialog on 401, and four screens: Dashboard, Ledger (+ edit), Quick-add, Categories (in Settings).

**Tech Stack:** Postgres 17 (Supabase image), Drizzle 0.45 + drizzle-kit 0.31, Hono 4, zod 4, Vue 3.5, Vuetify 4, TanStack Vue Query 5, Chart.js 4 + vue-chartjs 5, Vitest 5, Playwright 1.63.

**Spec:** `docs/superpowers/specs/2026-10-05-m1-spending-design.md`. Product: `docs/prd.md` §6.3–6.4. Technical: `docs/trd.md` §4–§7.

## Global Constraints

- Money: ¥ integers (`…Jpy`), ₹ integer paise in JSON (`…Paise`), `numeric(14,2)` in the database; rates are strings as stored (`numeric(12,6)`, e.g. `"1.694915"`). No floats for money.
- "Today" and cycles come from `@nri/core` (`todayIn`, `cycleOf`, `cycleBounds`); `toISOString` is banned by lint.
- Every handler filters by `c.var.userId` in addition to RLS. Another user's id is answered with 404 (path) or 400 (body), never 500.
- Limits: category name 1–40 chars, colour `#RRGGBB`, description ≤ 200, notes ≤ 2000, `q` ≤ 100, `pageSize` 1–200 (default 50).
- Errors use the existing envelope `{ error: { code, message, details? } }`; new code `AUTH_UNAVAILABLE` (503).
- All suites must stay green: `pnpm typecheck`, `pnpm lint`, `pnpm test:unit`, `pnpm test:scripts`, `pnpm stack:check`.
- Plan-level decisions against the spec (to ledger at Task 3): the category response carries `archived: boolean` instead of `archivedAt`, and the transaction response omits `createdAt`/`updatedAt` — the UI needs neither, and it avoids serialising timestamps (the lint rule bans `toISOString`). Category reorder uses up/down buttons instead of drag handles (keyboard-accessible, no drag library).

## Review Focus

1. A ₹ entry whose planning rate later changes: the stored ¥ must not change unless the amount itself is edited; an edit converts at the current rate. Covered in Task 6.
2. Text search with `%`, `_` or `\` in `q` must match those characters literally, not as wildcards. Covered in Task 6.
3. Cycle boundaries: a transaction on the 24th belongs to the cycle ending that day and one on the 25th to the next; December 25 rolls into January of the next year — in the ledger filter and on the dashboard. Covered in Tasks 2, 6, 7.
4. Reordering categories with a list that omits one of mine, repeats one, or includes another user's id must be refused without changing any order. Covered in Task 5.
5. A 401 during a session must keep what I typed in the quick-add or edit form (dialog, no navigation), while a 503 `AUTH_UNAVAILABLE` must not sign me out. Covered in Tasks 4 and 8.

export function previousCycle(cycle: Cycle): Cycle {
  const [y, m] = cycle.split('-').map(Number) as [number, number]
  return m === 1 ? `${y - 1}-12` : `${y}-${pad(m - 1)}`
}

export function nextCycle(cycle: Cycle): Cycle {
  const [y, m] = cycle.split('-').map(Number) as [number, number]
  return m === 12 ? `${y + 1}-01` : `${y}-${pad(m + 1)}`
}

/** Inclusive, oldest first; empty when `from` is after `to`. YYYY-MM strings compare correctly as text. */
export function cycleRange(from: Cycle, to: Cycle): Cycle[] {
  const out: Cycle[] = []
  for (let c = from; c <= to; c = nextCycle(c)) out.push(c)
  return out
}

export function lastCycles(end: Cycle, n: number): Cycle[] {
  let start = end
  for (let i = 1; i < n; i++) start = previousCycle(start)
  return cycleRange(start, end)
}

```ts
import { cycleOf, type Cycle, type IsoDate } from './cycles'

export type SpendRow = { occurredOn: IsoDate; amountJpy: number; categoryId: string }
export type RemitRow = { sentOn: IsoDate; jpySent: number; feeJpy: number }
export type CycleSummary = {
  incomeJpy: number
  spentJpy: number
  sentJpy: number
  feesJpy: number
  keptJpy: number
  savingsRatePct: number | null
}

const sum = (xs: number[]) => xs.reduce((a, b) => a + b, 0)

/** DASH-2. Remittance fees are reported apart from money sent and are not spending (PRD open question 1). */
export function summarizeCycle(input: {
  transactions: SpendRow[]
  remittances: RemitRow[]
  salaryJpy: number
  cycle: Cycle
  startDay: number
}): CycleSummary {
  const { cycle, startDay, salaryJpy } = input
  const spent = input.transactions.filter((t) => cycleOf(t.occurredOn, startDay) === cycle)
  const sent = input.remittances.filter((r) => cycleOf(r.sentOn, startDay) === cycle)
  const spentJpy = sum(spent.map((t) => t.amountJpy))
  const sentJpy = sum(sent.map((r) => r.jpySent))
  const keptJpy = salaryJpy - spentJpy - sentJpy
  return {
    incomeJpy: salaryJpy,
    spentJpy,
    sentJpy,
    feesJpy: sum(sent.map((r) => r.feeJpy)),
    keptJpy,
    savingsRatePct: salaryJpy > 0 ? Math.round((keptJpy * 1000) / salaryJpy) / 10 : null,
  }
}

/** DASH-3 donut: spend per category in the cycle, largest first (ties by id, for a stable order). */
export function spendByCategory(transactions: SpendRow[], cycle: Cycle, startDay: number) {
  const totals = new Map<string, number>()
  for (const t of transactions) {
    if (cycleOf(t.occurredOn, startDay) === cycle) totals.set(t.categoryId, (totals.get(t.categoryId) ?? 0) + t.amountJpy)
  }
  return [...totals]
    .map(([categoryId, spentJpy]) => ({ categoryId, spentJpy }))
    .sort((x, y) => y.spentJpy - x.spentJpy || x.categoryId.localeCompare(y.categoryId))
}

/** DASH-3 bar: spend per cycle for the given cycles, zero-filled, in the given order. */
export function spendByCycle(transactions: SpendRow[], cycles: Cycle[], startDay: number) {
  const totals = new Map(cycles.map((c) => [c, 0]))
  for (const t of transactions) {
    const c = cycleOf(t.occurredOn, startDay)
    if (totals.has(c)) totals.set(c, totals.get(c)! + t.amountJpy)
  }
  return cycles.map((cycle) => ({ cycle, spentJpy: totals.get(cycle)! }))
}
```

import type { Category } from '@nri/contracts'
import { categories, type Tx } from '@nri/db'
import { ApiError } from '../errors'

/** My categories with usage and the last payment method / need-want used (quick-add defaults). */
export async function listCategories(tx: Tx, userId: string, id?: string): Promise<Category[]> {
  const rows = await tx.execute<Category>(sql`
    select c.id, c.name, c.color, c.sort_order as "sortOrder", c.archived_at is not null as archived,
      (exists (select 1 from transactions t where t.user_id = c.user_id and t.category_id = c.id)
        or exists (select 1 from category_budgets b where b.user_id = c.user_id and b.category_id = c.id)) as "inUse",
      l.payment_method as "lastPaymentMethod", l.need_want as "lastNeedWant"
    from categories c
    left join lateral (
      select t.payment_method, t.need_want from transactions t
      where t.user_id = c.user_id and t.category_id = c.id
      order by t.occurred_on desc, t.created_at desc limit 1
    ) l on true
    where c.user_id = ${userId} ${id ? sql`and c.id = ${id}` : sql``}
    order by c.sort_order, c.name`)
  return [...rows]
}

export async function getCategory(tx: Tx, userId: string, id: string): Promise<Category> {
  const [c] = await listCategories(tx, userId, id)
  if (!c) throw new ApiError(404, 'NOT_FOUND', 'That category no longer exists')
  return c
}

export async function reorderCategories(tx: Tx, userId: string, ids: string[]) {
  const mine = (await tx.select({ id: categories.id }).from(categories).where(eq(categories.userId, userId))).map((r) => r.id)
  const given = new Set(ids)
  if (given.size !== ids.length || ids.length !== mine.length || mine.some((id) => !given.has(id))) {
    throw new ApiError(400, 'VALIDATION_FAILED', 'ids must list each of your categories exactly once')
  }
  for (const [i, id] of ids.entries()) {
    await tx.update(categories).set({ sortOrder: i }).where(and(eq(categories.id, id), eq(categories.userId, userId)))
  }
}

import type { Transaction, TransactionCreate, TransactionPatch, TransactionQuery } from '@nri/contracts'
import { cycleBounds, cycleOf, decimalFromPaise, jpyFromInrPaise, paiseFromDecimal } from '@nri/core'
import { accounts, categories, transactions, type Tx } from '@nri/db'
import { ApiError } from '../errors'
import { getProfileRow, requireProfile } from './profile'

type Row = typeof transactions.$inferSelect

export function toTransaction(r: Row, startDay: number): Transaction {
  return {
    id: r.id,
    occurredOn: r.occurredOn,
    cycle: cycleOf(r.occurredOn, startDay),
    categoryId: r.categoryId,
    accountId: r.accountId,
    description: r.description,
    amountJpy: r.amountJpy,
    enteredCurrency: r.enteredCurrency,
    amountInrPaise: r.amountInr === null ? null : paiseFromDecimal(r.amountInr),
    rateUsed: r.rateUsed,
    paymentMethod: r.paymentMethod,
    needWant: r.needWant,
    notes: r.notes,
  }

const invalid = (path: string, message: string) =>
  new ApiError(400, 'VALIDATION_FAILED', message, [{ path: [path], message }])

async function checkCategory(tx: Tx, userId: string, id: string, mustBeActive: boolean) {
  const [c] = await tx.select({ archivedAt: categories.archivedAt }).from(categories)
    .where(and(eq(categories.id, id), eq(categories.userId, userId)))
  if (!c) throw invalid('categoryId', 'That category does not exist')
  if (mustBeActive && c.archivedAt) throw invalid('categoryId', 'That category is archived')
}

async function checkAccount(tx: Tx, userId: string, id: string | null | undefined) {
  if (!id) return
  const [acc] = await tx.select({ id: accounts.id }).from(accounts)
    .where(and(eq(accounts.id, id), eq(accounts.userId, userId), isNull(accounts.archivedAt)))
  if (!acc) throw invalid('accountId', 'That account does not exist')
}

/** ¥ as given, or ₹ converted at the current planning rate (TXN-4); stored, never recomputed later. */
async function amountFields(tx: Tx, userId: string, input: { amountJpy?: number; amountInrPaise?: number }) {
  if (input.amountJpy !== undefined) {
    return { amountJpy: input.amountJpy, enteredCurrency: 'JPY' as const, amountInr: null, rateUsed: null }
  }
  if (input.amountInrPaise === undefined) return {}
  const rate = (await requireProfile(tx, userId)).planningRateJpyPerInr
  const amountJpy = jpyFromInrPaise(input.amountInrPaise, rate)
  if (amountJpy < 1) throw invalid('amountInrPaise', 'That amount is less than ¥1 at the planning rate')
  return { amountJpy, enteredCurrency: 'INR' as const, amountInr: decimalFromPaise(input.amountInrPaise), rateUsed: rate }
}

async function startDayFor(tx: Tx, userId: string) {
  return (await getProfileRow(tx, userId))?.cycleStartDay ?? 25
}

export async function createTransaction(tx: Tx, userId: string, input: TransactionCreate): Promise<Transaction> {
  await checkCategory(tx, userId, input.categoryId, true)
  await checkAccount(tx, userId, input.accountId)
  const { amountJpy: _j, amountInrPaise: _p, ...rest } = input
  const [row] = await tx.insert(transactions)
    .values({ userId, ...rest, accountId: input.accountId ?? null, ...(await amountFields(tx, userId, input)) } as typeof transactions.$inferInsert)
    .returning()
  return toTransaction(row!, await startDayFor(tx, userId))
}

export async function updateTransaction(tx: Tx, userId: string, id: string, input: TransactionPatch): Promise<Transaction> {
  const [existing] = await tx.select().from(transactions).where(and(eq(transactions.id, id), eq(transactions.userId, userId)))
  if (!existing) throw new ApiError(404, 'NOT_FOUND', 'That expense no longer exists')
  if (input.categoryId !== undefined && input.categoryId !== existing.categoryId) await checkCategory(tx, userId, input.categoryId, true)
  if (input.accountId !== undefined) await checkAccount(tx, userId, input.accountId)
  const { amountJpy: _j, amountInrPaise: _p, ...rest } = input
  const [row] = await tx.update(transactions)
    .set({ ...rest, ...(await amountFields(tx, userId, input)), updatedAt: sql`now()` })
    .where(and(eq(transactions.id, id), eq(transactions.userId, userId)))
    .returning()
  return toTransaction(row!, await startDayFor(tx, userId))
}

export async function getTransaction(tx: Tx, userId: string, id: string): Promise<Transaction> {
  const [row] = await tx.select().from(transactions).where(and(eq(transactions.id, id), eq(transactions.userId, userId)))
  if (!row) throw new ApiError(404, 'NOT_FOUND', 'That expense no longer exists')
  return toTransaction(row, await startDayFor(tx, userId))
}

export async function deleteTransaction(tx: Tx, userId: string, id: string) {
  const gone = await tx.delete(transactions).where(and(eq(transactions.id, id), eq(transactions.userId, userId))).returning({ id: transactions.id })
  if (!gone.length) throw new ApiError(404, 'NOT_FOUND', 'That expense no longer exists')
}

/** ILIKE pattern that matches `q` literally (backslash is Postgres's default LIKE escape). */
const likeLiteral = (q: string) => `%${q.replace(/[\\%_]/g, (m) => `\\${m}`)}%`

const SORT = {
  occurredOn: transactions.occurredOn,
  amountJpy: transactions.amountJpy,
  category: categories.name,
  paymentMethod: transactions.paymentMethod,
  needWant: transactions.needWant,
  description: transactions.description,
} as const

export async function listTransactions(tx: Tx, userId: string, q: TransactionQuery) {
  const startDay = await startDayFor(tx, userId)
  const where: SQL[] = [eq(transactions.userId, userId)]
  if (q.cycle) {
    const { start, end } = cycleBounds(q.cycle, startDay)
    where.push(between(transactions.occurredOn, start, end))
  }
  if (q.categoryId) where.push(eq(transactions.categoryId, q.categoryId))
  if (q.paymentMethod) where.push(eq(transactions.paymentMethod, q.paymentMethod))
  if (q.needWant) where.push(eq(transactions.needWant, q.needWant))
  if (q.q) where.push(or(ilike(transactions.description, likeLiteral(q.q)), ilike(transactions.notes, likeLiteral(q.q)))!)
  const cond = and(...where)
  const direction = q.dir === 'asc' ? asc : desc

  const rows = await tx.select({ t: transactions }).from(transactions)
    .innerJoin(categories, eq(categories.id, transactions.categoryId))
    .where(cond)
    .orderBy(direction(SORT[q.sort]), desc(transactions.createdAt), asc(transactions.id))
    .limit(q.pageSize).offset((q.page - 1) * q.pageSize)
  const [totals] = await tx.select({
    total: sql<number>`count(*)`.mapWith(Number),
    totalJpy: sql<number>`coalesce(sum(${transactions.amountJpy}), 0)`.mapWith(Number),
  }).from(transactions).where(cond)

  return { items: rows.map((r) => toTransaction(r.t, startDay)), total: totals!.total, page: q.page, pageSize: q.pageSize, totalJpy: totals!.totalJpy }
}

import { Hono } from 'hono'
import { and, between, eq } from 'drizzle-orm'
import { CycleString, Dashboard } from '@nri/contracts'
import { cycleBounds, cycleOf, lastCycles, spendByCategory, spendByCycle, summarizeCycle, todayIn } from '@nri/core'
import { categories, remittances, transactions } from '@nri/db'
import { ApiError } from '../errors'
import type { AppVars } from '../middleware/db'
import { requireProfile } from '../services/profile'

export const dashboardRoutes = new Hono<{ Variables: AppVars }>().get('/', async (c) => {
  const { db, userId } = c.var
  const profile = await requireProfile(db, userId)
  const startDay = profile.cycleStartDay
  const param = c.req.query('cycle')
  const parsed = param === undefined || param === '' ? null : CycleString.safeParse(param)
  if (parsed && !parsed.success) throw new ApiError(400, 'VALIDATION_FAILED', 'cycle must be YYYY-MM', parsed.error.issues)
  const cycle = parsed?.data ?? cycleOf(todayIn(profile.timezone), startDay)

  const cycles = lastCycles(cycle, 12)
  const { start, end } = cycleBounds(cycle, startDay)
  const historyStart = cycleBounds(cycles[0]!, startDay).start
  const spend = await db
    .select({ occurredOn: transactions.occurredOn, amountJpy: transactions.amountJpy, categoryId: transactions.categoryId })
    .from(transactions)
    .where(and(eq(transactions.userId, userId), between(transactions.occurredOn, historyStart, end)))
  const sent = await db
    .select({ sentOn: remittances.sentOn, jpySent: remittances.jpySent, feeJpy: remittances.feeJpy })
    .from(remittances)
    .where(and(eq(remittances.userId, userId), between(remittances.sentOn, start, end)))
  const cats = new Map(
    (await db.select({ id: categories.id, name: categories.name, color: categories.color }).from(categories)
      .where(eq(categories.userId, userId))).map((r) => [r.id, r]),
  )

  return c.json(Dashboard.parse({
    cycle, start, end,
    ...summarizeCycle({ transactions: spend, remittances: sent, salaryJpy: profile.salaryJpy, cycle, startDay }),
    byCategory: spendByCategory(spend, cycle, startDay).map((s) => ({ ...s, name: cats.get(s.categoryId)!.name, color: cats.get(s.categoryId)!.color })),
    byCycle: spendByCycle(spend, cycles, startDay),

const jpy = new Intl.NumberFormat('ja-JP', { style: 'currency', currency: 'JPY' })
const inr = new Intl.NumberFormat('en-IN', { style: 'currency', currency: 'INR', minimumFractionDigits: 2 })
const MONTHS = ['Jan', 'Feb', 'Mar', 'Apr', 'May', 'Jun', 'Jul', 'Aug', 'Sep', 'Oct', 'Nov', 'Dec']

export const yen = (n: number) => jpy.format(n)
export const rupees = (paise: number) => inr.format(paise / 100)

/** "25 Sep – 24 Oct 2026"; the start year is shown only when it differs from the end year. */
export function cycleLabel(cycle: string, startDay: number): string {
  const { start, end } = cycleBounds(cycle, startDay)
  const part = (d: string) => { const [y, m, day] = d.split('-').map(Number) as [number, number, number]; return { y, text: `${day} ${MONTHS[m - 1]}` } }
  const s = part(start)
  const e = part(end)
  return s.y === e.y ? `${s.text} – ${e.text} ${e.y}` : `${s.text} ${s.y} – ${e.text} ${e.y}`
}

import { CategoryList, type Category } from '@nri/contracts'

  '#4caf50', '#2196f3', '#ff9800', '#e91e63', '#9c27b0', '#00bcd4',

export const useCategories = () =>
  useQuery({ queryKey: ['categories'], queryFn: async () => (await apiFetch('/api/categories', {}, CategoryList)).items })

export const activeCategories = (list: Category[]) => list.filter((c) => !c.archived)

/** New order after moving the id at `index` by `delta` (−1 up, +1 down); unchanged at the ends. */
export function moveId(ids: string[], index: number, delta: number): string[] {
  const to = index + delta
  if (to < 0 || to >= ids.length) return ids
  const next = [...ids]
  ;[next[index], next[to]] = [next[to]!, next[index]!]
  return next
}

import type { Category, NeedWant, PaymentMethod } from '@nri/contracts'
import { jpyFromInrPaise, paiseFromDecimal } from '@nri/core'

export type Currency = 'JPY' | 'INR'
export const PAYMENT_LABELS: Record<PaymentMethod, string> = { bank: 'Bank', cash: 'Cash', credit_card: 'Credit card', ic_card: 'IC card' }
export const NEED_LABELS: Record<NeedWant, string> = { need: 'Need', want: 'Want' }

/** Quick-add defaults: what I used last time in this category (decided with the user), else Bank / Need. */
export function defaultsFor(c: Pick<Category, 'lastPaymentMethod' | 'lastNeedWant'> | undefined) {
  return { paymentMethod: c?.lastPaymentMethod ?? ('bank' as PaymentMethod), needWant: c?.lastNeedWant ?? ('need' as NeedWant) }
}

/** ¥: whole numbers (commas allowed). ₹: up to two decimals, sent as paise. Null when not a positive amount. */
export function parseAmount(text: string, currency: Currency): { amountJpy: number } | { amountInrPaise: number } | null {
  const s = text.replace(/,/g, '').trim()
  if (currency === 'JPY') {
    if (!/^\d+$/.test(s)) return null
    const n = Number(s)
    return n > 0 && Number.isSafeInteger(n) ? { amountJpy: n } : null
  }
  if (!/^\d+(\.\d{1,2})?$/.test(s)) return null
  const paise = paiseFromDecimal(s)
  return paise > 0 ? { amountInrPaise: paise } : null
}

export function previewJpy(text: string, rate: string): number | null {
  const a = parseAmount(text, 'INR')
  return a && 'amountInrPaise' in a ? jpyFromInrPaise(a.amountInrPaise, rate) : null
}

import type { NeedWant, PaymentMethod, SortField, Transaction, TransactionCreate } from '@nri/contracts'

export type LedgerState = {
  cycle: string | null
  categoryId: string | null
  paymentMethod: PaymentMethod | null
  needWant: NeedWant | null
  q: string
  sort: { key: SortField; order: 'asc' | 'desc' }
  page: number
}
type RouteQuery = Record<string, unknown>
const str = (v: unknown) => (typeof v === 'string' ? v : '')
const KEYS = ['cycle', 'categoryId', 'paymentMethod', 'needWant', 'q', 'sort', 'dir', 'page'] as const
export const PAGE_SIZE = 50

/** The page URL is the source of truth for filters/sort/page (reload and back/forward keep them). */
export function toApiQuery(route: RouteQuery): URLSearchParams {
  const p = new URLSearchParams()
  for (const k of KEYS) if (str(route[k])) p.set(k, str(route[k]))
  p.set('pageSize', String(PAGE_SIZE))
  return p
}

export function sortFromRoute(route: RouteQuery): { key: SortField; order: 'asc' | 'desc' }[] {
  const key = (str(route.sort) || 'occurredOn') as SortField
  return [{ key, order: str(route.dir) === 'asc' ? 'asc' : 'desc' }]
}

export function routeQueryFrom(s: LedgerState): Record<string, string> {
  const q: Record<string, string> = {}
  if (s.cycle) q.cycle = s.cycle
  if (s.categoryId) q.categoryId = s.categoryId
  if (s.paymentMethod) q.paymentMethod = s.paymentMethod
  if (s.needWant) q.needWant = s.needWant
  if (s.q.trim()) q.q = s.q.trim()
  if (!(s.sort.key === 'occurredOn' && s.sort.order === 'desc')) { q.sort = s.sort.key; q.dir = s.sort.order }
  if (s.page > 1) q.page = String(s.page)
  return q
}

/** Undo after delete: re-create from the copy kept client-side, in the currency it was entered in. */
export function toCreateInput(t: Transaction): TransactionCreate {
  const common = {
    occurredOn: t.occurredOn, categoryId: t.categoryId, accountId: t.accountId, description: t.description,
    notes: t.notes, paymentMethod: t.paymentMethod, needWant: t.needWant,
  }
  return t.enteredCurrency === 'INR' && t.amountInrPaise !== null ? { ...common, amountInrPaise: t.amountInrPaise } : { ...common, amountJpy: t.amountJpy }
}

  return {
